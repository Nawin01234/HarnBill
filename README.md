# 🧾 หารบิล (HarnBill)

หารบิลกับเพื่อนแบบเรียลไทม์ — คนจ่ายใส่รายการ ส่งลิงก์ เพื่อนติ๊กสิ่งที่กิน
ทุกคนเห็นยอดตัวเองทันที และได้ **QR พร้อมเพย์ตามยอดของตัวเอง** สแกนจ่ายจบ ไม่ต้องลงแอป ไม่ต้องสมัคร

## รัน

```bash
cd frontend && npm install && npm run build && cd ..
cd backend && cargo run --release
```

เซิร์ฟเวอร์จะพิมพ์สองลิงก์:
- `http://localhost:8080` — เปิดบนเครื่องนี้
- `http://192.168.x.x:8080` — **ใช้ลิงก์นี้** เพื่อให้เพื่อนที่ต่อ Wi-Fi เดียวกันเข้าได้

ตัวเลือก: `--port 8080` `--db harnbill.db` · ห้องจะถูกลบอัตโนมัติหลัง 30 วัน
ถ้าอยากให้เพื่อนเข้าจากที่ไหนก็ได้ ต้องเอาขึ้นเซิร์ฟเวอร์ที่มีโดเมน (เช่น VPS, Fly.io)

## วิธีคิดเงิน (ทุกอย่างเป็นสตางค์ ไม่มีเศษหาย)

1. แต่ละรายการหารเท่ากันตามคนที่ติ๊ก (รายการ "หารทุกคน" หารทุกคนในห้อง)
2. ส่วนลดเฉลี่ยตามสัดส่วนที่แต่ละคนกิน
3. เซอร์วิสชาร์จคิดจาก (ยอด − ส่วนลด)
4. VAT คิดจาก (ยอดหลังส่วนลด + เซอร์วิส)
5. ปัดเศษแบบ largest remainder → **ยอดทุกคนรวมกันเท่ากับยอดบิลพอดีเสมอ** (มี fuzz test 300 บิลสุ่ม)

## สิทธิ์

- คนเปิดบิล: แก้รายการ/ราคา/ตั้งค่า, ติ๊กแทนเพื่อน, ยืนยันรับเงิน
- เพื่อน: ติ๊กได้เฉพาะของตัวเอง, กด "ฉันโอนแล้ว"
- เลขพร้อมเพย์แสดงแค่ 4 ตัวท้าย, token ไม่เคยถูกส่งให้คนอื่น

## โครงสร้าง

- `backend/` Rust — axum (REST + WebSocket), SQLite, `qrcode`
  - `money.rs` คำนวณยอด · `promptpay.rs` สร้าง payload EMVCo + CRC16 · `hub.rs` ห้อง/สิทธิ์/บันทึก · `api.rs` HTTP
- `frontend/` Svelte 5 + Vite + TS, mobile-first, รองรับ dark mode

ทดสอบ: `cd backend && cargo test`
